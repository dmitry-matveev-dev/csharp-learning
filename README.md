# C# Learning Journey

Мой путь от основ C# до стажировки Backend .NET.

Здесь я публикую весь учебный код, который пишу ежедневно:
уроки, упражнения и домашние задания. Каждый день — новые коммиты.

## Структура

| Папка | Что внутри |
|---|---|
| `01-freecodecamp/` | Код из уроков FreeCodeCamp (Foundational C# with Microsoft) |
| `02-exercism/` | Решения упражнений трека C# на Exercism |
| `03-homework/` | Домашние задания по дням (День 1, День 2, ...) |

## Стек на данный момент

- C# / .NET 9
- Visual Studio 2022
- Консольные приложения

## Цель

Пройти подготовку по плану наставника и поступить на стажировку
Backend C#/.NET в Innowise.
